The Nine Steps from Question to Answer

How a model turns a question into an answer, and the terms each step uses.

Terms Used in the Diagram

TermWhat It Is
Steps 1 to 3 · Text to Vectors
TokenA piece of text of about four characters; a common word is one token, a rare word several
VocabularyThe fixed list of tokens a model knows, from 32,000 to 256,000 depending on the model
TokenizerThe small program that cuts text into tokens and turns each into its Token ID
Token IDA token's number in the vocabulary
VectorThe list of numbers each Token ID becomes; every layer reads and updates it
Step 4 · Transformer
TransformerThe model itself: a stack of identical layers whose learned numbers, the weights, hold its knowledge
LayerOne block of the stack, doing two steps in order: Attention, then Feed-Forward
AttentionGathers context by blending in information from related earlier tokens
Feed-ForwardRecalls knowledge by transforming each token's vector on its own
KV CacheThe stored Keys and Values of earlier tokens, so they are never recomputed
Steps 5 and 6 · Picking a Token
Score and ProbabilityEvery token in the vocabulary gets a score, turned into probabilities that add up to one
SamplingPicking the next token by a weighted random draw
TemperatureHow random sampling is; at zero it always picks the most likely token
Steps 7 to 9 · The Loop
PassOne full run through all the layers, producing one token
PrefillThe first pass, which reads the whole question at once and sets the wait for the first word
DecodeEvery later pass, one per new token, with speed set by memory bandwidth
End-of-Text TokenA special token meaning finished, which the model learns in training
Length LimitThe maximum output length, which stops the loop if the End-of-Text Token never comes

C2

Number Formats and Tensor Cores

How storing each number in fewer bits speeds up chips and saves memory, and what it costs in accuracy.

PointDetail
Tensor CoreThe GPU unit that multiplies a small block of a matrix in one step rather than one number at a time; it carries almost all of the matrix maths in B4
Number FormatFP stands for floating point and INT for integer, and the figure is the number of bits per value; BF16, short for brain float, is a 16-bit format designed at Google
Range and PrecisionExponent bits set how large or small a value can be, and mantissa bits set how many significant digits it keeps; BF16 keeps the range of 32-bit numbers and gives up precision
SpeedEach halving of bits roughly doubles Tensor Core throughput, because twice as many multipliers fit into the same silicon area and power, so FP8 runs about twice and FP4 about four times as fast as BF16
MemoryA weight takes 2 bytes in BF16, 1 in FP8 and 0.5 in FP4, so a 70B model needs 140, 70 or 35 GB, and each Decode pass reads that much less from HBM
AccuracyFewer bits round more coarsely, so labs keep running sums in higher precision and give each block of 16 or 32 values its own scale factor; training mostly stays in BF16 and FP8
GenerationsEach accelerator generation adds hardware support for a smaller format, so the smallest format a model can use is set by the chip it runs on
Reading SpecsHeadline peaks often quote the smallest format with sparsity, which doubles the figure, so chips should be compared in the same format, dense

Glossary

Definitions of further terms.

TermWhat It Is
Models
Parameter or WeightA learned number inside the model; model size counts them
Context WindowThe most tokens a model can consider at once
AttentionThe mechanism that lets each token draw on earlier tokens
Mixture-of-ExpertsA design that routes each token to a few of many expert blocks
PretrainingLearning to predict the next token across trillions of tokens
Post-TrainingFine-tuning and reinforcement learning that turn a base model into an assistant
RLHFReinforcement learning from human feedback on preferred answers
Reasoning ModelA model that thinks in hidden tokens before it answers
DistillationTraining a small model to imitate a larger one
AgentA model in a loop that plans, uses tools and acts
Serving and Training
Test-Time ComputeComputation spent while answering rather than in training
QuantisationStoring weights in fewer bits, such as FP8 or FP4
Time to First TokenThe delay before the first output token appears
FLOPSFloating-point operations per second, where one PF is a thousand trillion
MFUModel FLOPs utilisation, the share of peak compute actually used
Hardware and Industry
HBMHigh-bandwidth memory: stacked DRAM placed beside the processor
CoWoSTSMC's packaging that joins logic dies and HBM on one interposer
NVLinkNVIDIA's high-speed link between GPUs inside a rack
Scale-Up and Scale-OutLinks within a rack, and links between racks
ASICA chip designed for one purpose, such as a TPU or Trainium
NeocloudA GPU-focused cloud provider such as CoreWeave or Nebius
HyperscalerThe largest cloud operators: Amazon, Microsoft and Google, with Meta by scale
PUEPower usage effectiveness: facility power divided by IT power
Run-RateRecent monthly revenue multiplied by twelve
LTALong-term agreement: a multi-year supply contract with committed volumes or prices
