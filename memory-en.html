D.2 NAND Structure and Types
ComponentWhat It Does
NAND Die
PlaneReads, writes and erases in parallel with the other planes
BlockSmallest unit that can be erased
PageSmallest unit that can be read or written
Word-Line LayersStacked layers, each a row of cells across the plane
Channel HolesVertical holes drilled through every layer
CellStores 3 bits in TLC or 4 in QLC where a hole crosses a layer
Bit LinesCarry data from the tops of the holes to the page buffers
Staircase ContactsStep down to every layer so the row decoders can reach it
Silicon SubstrateThe wafer the die is built on
CMOS Under the ArrayPuts the control circuits beneath the memory cells to save die area
Page BufferHolds a page of data on its way into or out of its plane
Row DecodersSelect the word line to read, write or erase
Charge PumpsMake the high voltages that program and erase the cells
Control LogicRuns the read, program and erase sequences
I/O InterfaceMoves data and commands between the die and the controller
I/O PadsConnect the die to the package through bond wires

SSD Controller

FunctionWhat It Does
Functions
Address MappingTracks which die, block and page holds each piece of host data; the map sits in the SSD's DRAM
Wear LevellingSpreads writes evenly so no block wears out early
Garbage CollectionMoves valid data out of used blocks and erases them for reuse
Error CorrectionFixes bit errors in data read from the NAND
Parallel AccessReads and writes across many channels and dies at once
Host InterfaceTalks to the host over PCIe and NVMe, or UFS and e.MMC
Encryption and Power-Loss ProtectionEncrypts data and, with the capacitors, saves it if power is cut
